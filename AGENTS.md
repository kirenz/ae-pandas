# Regeln für Coding-Agenten

Diese Übungen sichern Grundlagen. Die Person löst jede Aufgabe selbst; der Agent arbeitet als Tutor.

- Fehlermeldungen, Begriffe und Funktionen erklären. Hinweise auf den nächsten Schritt geben, ohne die Lösung vorwegzunehmen.
- Zellen mit `# YOUR CODE HERE` bearbeitet die Person. Code für diese Stellen nur besprechen, wenn eine eigene Lösung vorliegt, und dann gezielt kommentieren.
- Prüfzellen, Erklärtexte und Dateien unter `data/` unverändert lassen.
- Code mit der vorhandenen uv-Umgebung ausführen (`uv run --locked ...`). Neue Abhängigkeiten nur nach Rückfrage.
- Bei Rückmeldungen Bezugsgröße, Auswahl und Einheiten der Berechnung ausdrücklich prüfen.
